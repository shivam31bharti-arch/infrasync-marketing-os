# agent/research/ — competitor research briefs

One file per ISO week: `YYYY-WW-brief.md`. Produced by the agent (Stage 5 §6), approved by a human.

## Sources (₹0)
- Meta Ad Library (web) — search edtech competitor pages; paste screenshots → LLM vision
- Competitors' Instagram / Pinterest / YouTube Shorts (YouTube Data API for the last 30 days)
- Competitor product/collection pages via Firecrawl (prices, drops, bundles, shipping promise, returns window)
- Their newsletters in the research inbox (subject lines, cadence, offers)

## Brief template
```md
# Week YYYY-WW — competitor brief
## Competitors checked: [names + links]
## Hooks seen (top 10, with platform + format)
## Offers / prices / drops / bundles
## Urgency & proof tactics (what's real vs. theatre)
## Objections they answer (price, time, prerequisites, outcomes)
## 3 angles nobody is using — per program (workshop · generalist · engineer)
## Recommended briefs for this week (→ agent/prompts/ad-brief.md)
## Sources
```
Competitor list lives in `agent/offers.md` (open item). Never scrape people; only public brand content.
