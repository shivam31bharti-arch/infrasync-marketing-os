# Glossary

- **Stage 0 / 0.5** — accounts & keys (human-only) / machine + repo prep. Stages 1–6 = storefront, server, ad factory, growth engine, agent, operate.
- **EXECUTE / USER / DECISION class** — task types in the build loop: agent does it / human must do it / ask first.
- **Overhead vs COGS** — fixed monthly cost (cap ₹0–100) vs per-order cost (allowed, priced into products).
- **Free window (WhatsApp)** — 24h after a customer messages (replies free); 72h after a click-to-WhatsApp ad.
- **Utility / marketing template** — WhatsApp message types: ₹0.115 (order updates) / ₹0.86 (promotional, budget-capped).
- **Hero SKU** — the product an ad or brief is built around; must appear accurately in every clip.
- **Refs** — the 3 reference images per Flow clip (real product photos: front · detail · on-model).
- **Extend** — Flow feature continuing an 8-s clip; chain ×3 for a continuous 30-s take.
- **Brand DNA** — the brand profile (tone, audience, banned words, visual prefix) injected into every prompt; seeded from Pomelli.
- **Drafts queue** — Supabase `drafts` table; nothing outbound is sent without a human approving a row.
- **Segments** — new · browsed · carted · bought_once · repeat · lapsed (Supabase `subscribers.segment`).
- **Kill rule** — an ad/angle below half the median after 7 days is retired; winners get 3 variants.
- **Research inbox** — a Gmail subscribed to competitor newsletters for the weekly brief.
