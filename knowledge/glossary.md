# Glossary

- **Stage 0 / 0.5** — accounts & keys (human-only) / machine + repo prep. Stages 1–6 = program site, VPS, ad factory, growth engine, agent, operate.
- **EXECUTE / USER / DECISION class** — build-loop task types: agent does it / human must / ask first.
- **Overhead vs COGS** — fixed monthly cost (cap ₹0–100) vs per-sale cost (payment fees, WhatsApp utility — allowed).
- **The two tracks** — AI Generalist Accelerator (non-tech; vibe coding + AI tools) · AI Engineer Accelerator (Python required). Both $1,200 intl / ₹95,000 India.
- **Workshop** — the $20 2-day front door of the funnel; buyers beat freebie-seekers.
- **Track-fit quiz** — 5–7 question router recommending a track; result saved to the lead row.
- **Free window (WhatsApp)** — 24h after an inbound message (replies free); utility ₹0.115 / marketing ₹0.86 templates.
- **Refs** — the 3 reference images per Flow clip (host / studio / tool-screen scenes; never fake students).
- **Extend** — Flow feature continuing an 8-s clip; chain ×3 for a continuous 30-s take.
- **Drafts queue** — Supabase `drafts`; nothing outbound sends without human approval.
- **Segments** — new · engaged · workshop_registered · workshop_attended · quiz_generalist · quiz_engineer · enrolled · alumni · lapsed.
- **Kill rule** — an ad below half the median at day 7 is retired; winners get 3 variants.
- **Research inbox** — a Gmail subscribed to competitor funnels for the weekly brief.
- **Claims policy** — offers.md rules: no fake students, no outcome claims without data, Python prereq stated.
